# Necronomicon Providence 2026

There are many events over the long weekend that is Necronomicon Providence, and the information about those events is recorded across several sources, both HTML and PDF.

All sources have been saved here as either the original PDFs or as the web pages saved as PDF. Since all the Gaming programing is sign-up only, those events are not saved here (too late to sign up). Same goes for the Walking Tours.
